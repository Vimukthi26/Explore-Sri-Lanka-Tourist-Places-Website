# 🇱🇰 Explore Sri Lanka – Premium Tourism Website

Experience the magic of the Pearl of the Indian Ocean. This project is a stunning, high-performance tourism website designed to showcase Sri Lanka's most beautiful destinations, from ancient historical sites to pristine beaches.

![Explore Sri Lanka Hero](images/sigiriya.png)

## ✨ Key Features
- **Premium Design**: Modern, clean, and interactive UI with a focus on immersive imagery.
- **Fully Responsive**: Works perfectly on mobile, tablet, and desktop devices.
- **Dynamic Filtering**: Interactive "Must-Visit Places" section with category filtering.
- **Photo Gallery**: Specialized grid displaying breathtaking captures of Sri Lanka.
- **Interactive Elements**: Glassmorphism effects, scroll-reveal animations, and custom lightboxes.
- **SEO Optimized**: Built with semantic HTML and meta tags for better discoverability.

## 🛠️ Tech Stack
- **HTML5**: Semantic structure.
- **CSS3**: Vanilla CSS with custom properties (CSS variables), Grid, Flexbox, and advanced animations.
- **JavaScript**: Modern ES6+ for interactivity and scroll effects.

## 🚀 DevOps & CI/CD
This project includes a robust DevOps pipeline using **GitHub Actions**:
- **Code Linting**: Automatically validates HTML and CSS for best practices using `htmlhint` and `stylelint`.
- **Automatic Deployment**: (WIP) Integration with GitHub Pages for seamless updates.
